# Week 3 Java OOP Assignments

This repository contains 10 independent beginner-friendly Java programs. Each problem has its own folder and `Main.java`, so programs with the same supporting class name (such as `Employee`) remain separate.

## Assignment 1 - OOP Practice Problems

1. `Assignment1_Practice/M1_PlacementRecord` - From Parallel Arrays to a Class
2. `Assignment1_Practice/M2_MessWallet` - Encapsulated Mess-Card Wallet
3. `Assignment1_Practice/M3_Course` - Overloaded Constructors for a Course
4. `Assignment1_Practice/M4_IdCard` - Reference Copies and a Shared ID Card
5. `Assignment1_Practice/M5_StudentStatic` - Instance vs Static: Splitting a Class Correctly

## Assignment 2 - OOP Homework

1. `Assignment2_Homework/M1_BookInventory` - Library Inventory
2. `Assignment2_Homework/M2_PayrollAccount` - Encapsulated Payroll Account
3. `Assignment2_Homework/M3_EmployeeConstructors` - Overloaded Constructors for an Employee
4. `Assignment2_Homework/M4_HallTicket` - Reference Copies and a Shared Exam Hall Ticket
5. `Assignment2_Homework/M5_EmployeeStatic` - Instance vs Static: Splitting an Employee Class Correctly

## Compile and run

Open a terminal in any individual problem folder, then run:

```bash
javac Main.java
java Main
```

After running, remove generated class files before committing:

```bash
del *.class
```
